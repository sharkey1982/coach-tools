How the rotation works: split the group between the main and secondary activity, then swap. It does not matter which activity a gymnast completes first. The main theme receives the deeper coached progression that week; the secondary activity is a shorter revisit/exposure. Repeat the six-week cycle, entering each gymnast at their current progression rather than restarting the skill. The age bands below are guides only; recreational and squad placement should follow demonstrated ability.

Application & Variety

These are curriculum overlays, not extra compulsory theme weeks. Use them periodically in a secondary station, application block or final 10–15 minutes so technical repetition is retained.

Partner & Group Work

Synchronised skills, canon sequences, mirrored movement, paired balances and small-group challenges. Link them to the current technical theme rather than treating them as unrelated games.

Hand Apparatus

Occasional hoops, balls, ribbons, beanbags or ropes for balance, travelling, jumping, coordination, rhythm and exchanges. This is movement exploration rather than a separate rhythmic-gymnastics syllabus.

Composition

Short sequences combining balances, rotations, jumps, travel and a chosen skill. Increase requirements with ability: memory and clear shapes → links and direction → levels, synchronisation and performance quality.

End-of-term application: periodically replace a normal application block — or, where appropriate, a whole final session — with group routine building, performance and supervised gymnast choice/free practice. A useful routine brief is: one balance, one rotation, one jump, one travelling action, one skill of choice, one synchronised/group element, and clear start/finish positions. The rolling six-week cycle can simply resume where it stopped next term.
