Activities Admin

Football activities library · group, tag-variant, ready & draft flags

Adds a manifest-only stub (same shape as an existing "Full write-up pending" entry) — Ready and Draft are set automatically, so it won't open a full plan page until it's written up and marked ready. The id is generated from the name.

  • Group sets the bucket used everywhere else (Session Builder slots, Activities filter pills, Syllabus/Video Admin dropdowns). Within Movement skills, tick Tag variation only for a freeze/chase mechanic; tag Match Play by hand for small-sided/game-format activities.
  • Focus label is the chip text shown on the card — keep it specific (e.g. "Dribbling · Themed"), not the generic group name.
  • Ability is independent of year group — leave "— Not set —" if it suits any ability.
